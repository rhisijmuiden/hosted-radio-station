# Brand: RHIS

This project uses the RHIS house style. The files here are copied from the central
[rhis-huisstijl](https://github.com/rhisijmuiden/rhis-huisstijl) repository (root folder) and are the source for the admin panel:

| File | Used in |
| --- | --- |
| `tokens.css`, `tokens.json` | `apps/web/src/brand/tokens.css` (colours, type, spacing, radius; light and dark) |
| `logo/*.svg` | `apps/web/public/brand/` (sidebar, login page, favicon, "Powered by RHIS") |

Archivo (SIL Open Font License) is self-hosted from `apps/web/public/brand/archivo-latin.woff2`.

When the house style changes, update it in `rhis-huisstijl` first and copy the files here.
